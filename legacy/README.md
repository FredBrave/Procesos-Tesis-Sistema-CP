# Prototipo original GUIOSAD v0.1.2

Conservado sin cambios como referencia del algoritmo y de los datos.

- `main.py`, `guiosad.py` — app Python/Flexx (requiere `pip install flexx pandas`; ejecutar `python main.py`).
- `guiosad.html` — exportación HTML generada por Flexx.
- `guiosad_data.csv`, `factors.csv` — copiados a `../data/` (fuente de verdad actual).
- `MATRIZ RECOMENDACION GUIOSAD 2021.xlsx` — matriz de decisión A/B/C, transcrita en `../data/recomendaciones.json`.
- `Manual tecnico GUIOSPRO FLOSS.pdf` — manual de instalación del prototipo.

Repositorio original: https://github.com/victorreadoctorado/GUIOSPRO_FLOSS
